# Cron Job Results

Append-only log of cron job executions and outcomes.

## Format
```
## YYYY-MM-DD HH:MM — [Job Name]
**Status:** OK / WARN / FAIL
**Model used:** Haiku / Sonnet
**Duration:** Xs
**Output file:** path (if generated)
**Notes:** any issues or findings
```
